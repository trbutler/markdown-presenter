# Little Hills theme assets

- `logo.svg`: supplied Little Hills Church Logo 1.1d (Cleaned Up) for Web,
  April 8, 2021. Lettering is outlined; it has no external font dependency.
- `Quicksand.ttf`: upstream Google Fonts variable Quicksand, downloaded from
  `https://github.com/google/fonts/blob/main/ofl/quicksand/Quicksand%5Bwght%5D.ttf`
  on October 18, 2026. See `Quicksand-OFL.txt`.
- `SereneSands-Regular.woff2`: local alpha candidate, September 19, 2026 build.
  Source project: `https://github.com/trbutler/serene-sands`. The local font
  repository is under active development; this binary is pinned for preview,
  not claimed as the finished font. See `SereneSands-OFL.txt`.

The supplied Singular screenshot/recording and Motion project remain external
reference material, rather than shipping large source media in the theme.

Binary checksums are recorded in `SHA256SUMS`.
